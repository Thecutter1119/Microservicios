# Documentacion del proyecto DOM

Esta carpeta concentra la documentacion del microservicio ms-domicilios para separar claramente el analisis del codigo ejecutable.

## Contenido

- Modelado y requisitos en los archivos `DOM-*.md` de la raiz del workspace.
- Diagramas en `ms-domicilios-app/Documentacion/diagramas/` mientras se define la migracion definitiva de activos.

## Recomendacion de estructura final

- `docs/dom/` para requisitos, analisis y especificacion.
- `docs/dom/diagramas/` para diagramas PlantUML y exportados.
- `ms-domicilios-app/` para codigo, pruebas y configuracion de ejecucion.
